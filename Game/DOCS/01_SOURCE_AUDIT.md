# Star Spirit — аудит исходного материала

**Статус:** CONFIRMED / AUDIT BASELINE  
**Ветка:** `main`  
**Дата аудита:** 2026-08-19  
**Целевая версия проекта:** Godot 4.8  

## 1. Назначение

Этот документ фиксирует состояние исходных материалов проекта на момент аудита. Он не заменяет исторические источники и не определяет окончательную архитектуру игры.

Классификация сведений:

- **CONFIRMED** — прямо подтверждено источником.
- **INFERRED** — вывод из нескольких источников.
- **PROPOSED** — предложение аудитора.
- **UNCERTAIN** — недостаточно данных для надёжной интерпретации.
- **CONFLICTING** — источники несовместимы.

## 2. Состояние репозитория

### CONFIRMED

Репозиторий: `kinox7834/GAME`. Основная ветка: `main`.

На момент аудита корень содержит два функциональных слоя:

1. `Game/` — текущий минимальный проект Godot.
2. `IMPORT(INCOMPLETED, DONT DELETE)/` — исторический/исходный слой материалов.

Папка `IMPORT(INCOMPLETED, DONT DELETE)/` не изменялась и в дальнейшем должна рассматриваться как архив исходного замысла, а не как каноническая документация.

## 3. `Game/`

### CONFIRMED

В `Game/` обнаружены только:

- `Game/project.godot`
- `Game/icon.svg`
- `Game/icon.svg.import`

Не обнаружены:

- игровые сцены `.tscn`;
- скрипты `.gd`;
- пользовательские ресурсы игры;
- Autoload;
- готовые игровые UI;
- игровые системы;
- импортированные игровые ассеты.

`project.godot` содержит:

- `config_version=5`;
- имя приложения `Game`;
- `config/features=PackedStringArray("4.7", "Forward Plus")`;
- renderer/feature `Forward Plus`;
- `canvas_items` stretch mode;
- aspect `expand`;
- Jolt Physics для 3D;
- Windows D3D12 driver.

### CONFLICTING / TECHNICAL DECISION PENDING

Целевая версия проекта — **Godot 4.8**, однако фактический `project.godot` заявляет feature **4.7**.

Это зафиксировано как нерешённое техническое решение. Автоматическое исправление в рамках аудита не выполнялось.

## 4. Исторические текстовые источники

## 6. DOCX и невозможность полного извлечения

### UNCERTAIN

В историческом слое присутствуют бинарные `.docx` документы. GitHub-коннектор позволил подтвердить их существование, размеры и расположение, а также получить бинарное представление отдельных файлов, однако в текущем интерфейсе чтение бинарного содержимого DOCX не удалось довести до надёжно декодированного текста.

Поэтому содержимое этих DOCX **не используется как подтверждённый источник фактов**, кроме сведений, которые очевидны из самого пути/имени файла.

Перечень обнаруженных DOCX включает документы, относящиеся как минимум к:

- вращающейся крысе;
- стреляющей крысе;
- крестьянскому дому;
- кровавому посоху;
- оружиям в корне категории `Оружия`;
- слаймовому пистолету;
- каштану.

## 7. Канонический статус источников

### CONFIRMED

Текущая каноническая база должна строиться из подтверждённого материала ниже:

1. фактическое содержимое пяти TXT-документов;
2. фактическое состояние `Game/project.godot`;
3. фактическое наличие и структура ассетов;
4. только те визуальные/функциональные свойства ассетов, которые прямо названы или очевидно следуют из самого материала.

Нельзя считать автоматически каноном:

- имена папок как описание окончательной игровой логики;
- пометки `Возможно...` как факт;
- характеристики из нечитанных DOCX;
- окончательную архитектуру Godot;
- отсутствующие системы, которые не были описаны источниками.

## 8. Важные исходные идеи

### CONFIRMED

Из текстовых источников явно следуют:

- название игры: **Star Spirit**;
- жанровое ядро: **2D metroidvania + action**;
- большой связанный мир с множеством локаций;
- бэктрекинг и постепенное открытие новых маршрутов/возможностей;
- боевая система с оружием, активными и пассивными предметами;
- множество оружия и боссов;
- боково-сверху направленная камера;
- пиксельный визуальный стиль;
- безопасные и враждебные зоны;
- возможность строить билды;
- ограничение экипировки через количество рук, с возможностью влияния улучшений;
- слизь, связанная с главным героем и способная превращаться в оружие;
- разные варианты слизи с разными ветками развития и количеством слотов;
- сюжетная цель, связанная с Лабораторией, где герой был создан и где его предал брат;
- объект №1817 как разумная слизь в отчётах корпуса Лямбда;
- управление для PlayStation и клавиатуры;
- сохранения и как минимум две задуманные сложности;
- отдельная музыкальная тема для многих боссов и музыка локаций.

## 9. Ограничения аудита

### CONFIRMED

Аудит не реализовывал gameplay, не создавал сцены/скрипты и не изменял `IMPORT(INCOMPLETED, DONT DELETE)`.

### PROPOSED

Следующая документация должна использовать отдельные уровни уверенности и ссылаться на конкретные исходники. Новые игровые правила не следует добавлять в каноническую базу без отдельного решения.
